# الحق ايه

تطبيق شخصي بالعربي لحساب الوقت المتاح قبل المعاد الجاي. المواعيد والمهام بتتحفظ في المتصفح، وملف JSON ينقلهم بين الأجهزة.

## التشغيل على اللاب

استخدم Node.js 22.12 أو أحدث. افتح الطرفية جوه فولدر `catch-up` وشغّل:

```bash
npm ci
npm run dev
```

افتح العنوان اللي Vite بيطبعه. بعد أي تعديل، `npm run build` بيحدّث فولدر `dist`، و`npm run preview` يشغّل النسخة النهائية محليًا.

## الرفع على Cloudflare

الأرشيف فيه فولدر `dist` جاهز. من Cloudflare Dashboard ادخل **Workers & Pages**، واستخدم [Pages Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/). ارفع فولدر `dist` نفسه عشان `index.html` يكون في جذر الموقع. البيانات تفضل في المتصفح على عنوان الموقع. لو دخلت بيانات أثناء التشغيل المحلي وعايزها على اللينك المنشور، صدّرها من النسخة المحلية واستوردها من اللينك.

## الرفع على GitHub Pages

فولدر `github-pages` فيه نسخة النشر الجاهزة. ارفع **محتوياته** إلى جذر الريبو بحيث يظهر `index.html` بجانب مجلدات `assets` و`icons`. اختار **Settings → Pages → Deploy from a branch → main → /(root)**. عند تحديث نسخة موجودة، وافق على استبدال `index.html` وارفع باقي الملفات الجديدة معاه.

لو عدّلت السورس وعايز تنشره تاني، شغّل `npm run build -- --base ./` عشان يتجدد `dist` بمسارات مناسبة لـGitHub Pages. انسخ ملفات البناء إلى فولدر النشر، وسيب `.nojekyll` موجود. ملف `_headers` إعداد خاص بـCloudflare.

## تثبيت الموقع ومعاينة المشاركة

بعد نجاح النشر، افتح اللينك HTTPS في Chrome على أندرويد ومن قائمة ⋮ اختار **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**. على iPhone، افتح Safari واختر **مشاركة → إضافة إلى الشاشة الرئيسية**. ملفات الاسم والأيقونات موجودة في `public/manifest.webmanifest` و`public/icons/`. فتح الموقع يحتاج اتصال؛ تشغيله من غير إنترنت لسه مؤجل.

عنوان المعاينة ووصفها في `index.html`، وصورتها في `public/share-preview.png`. قيمة `VITE_SITE_URL` في `.env.production` مضبوطة على `https://m7md-3bdo.github.io/catch-up/`. لو نشرت على رابط مختلف، غيّر القيمة للرابط الجديد كاملًا مع الشرطة المائلة في آخره، وبعدها اعمل Build من جديد.

## الوقت بيتحسب إزاي؟

1. `getTodayPlan` بتجيب أقرب معاد لسه هيبدأ **النهارده** حسب تاريخ الجهاز. لو فيه معاد بدأ بالفعل، بتحسب نهايته من وقت البداية والمدة.
2. وقت التحرك = بداية المعاد الجاي − وقت الطريق. بداية الوقت المتاح هي الوقت الحالي، أو نهاية المعاد الجاري لو أنت لسه فيه.
3. الدقايق المتاحة هي الفرق بين الوقتين، مقرب لأسفل، وبحد أدنى صفر. لو معادك الحالي يخلص ٤:٠٠ والجاي ٥:٠٠ وطريقه ٣٠ دقيقة، يبقى هتتحرك ٤:٣٠ وقدامك ٣٠ دقيقة.
4. كل مهمة مدتها تكفي بتظهر كاقتراح مستقل. الأولوية الأعلى تظهر الأول، وبعدها أقرب موعد تسليم. ولما ميبقاش فيه معاد تاني النهارده، تظهر كل المهام غير المكتملة.

المعاد الفردي بيتحفظ كلحظة ثابتة، والساعة اللي بتظهر ليك بتتبع توقيت الجهاز وقت العرض. المعاد الأسبوعي بيتحفظ كيوم وساعة محليين، مع تاريخ بداية وتاريخ انتهاء اختياري شامل آخر يوم. كل تكرار بيتبني باستخدام توقيت الجهاز في يومه، فساعة الدرس على الساعة المحلية تفضل زي ما هي عبر التوقيت الصيفي. لو الساعة المحلية اتكررت، الحساب يستخدم أول مرة. لو الساعة اختفت، صفحة النهارده تعرض تنبيه عشان تعدّل اليوم ده. الاستثناء مربوط بتاريخ اليوم الأصلي حتى لو نقلته ليوم تاني.

الساعة بتتحدث كل ثانية وعند الرجوع للتبويب. مع منتصف الليل تظهر مواعيد اليوم الجديد، والمعاد الجاري اللي بدأ امبارح يفضل محسوب لحد نهايته.
